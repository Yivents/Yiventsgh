A QR ticket you can scan at the door

Tickets are rendered on demand from one shared component. The QR code contains only a random code — no personal information, no payment data. Yivents never stores a generated ticket file.

Door staff use a per-event link and PIN. No door-staff accounts, no database role field.

Money rule

Yivents never receives or processes payments. Attendees pay the organizer directly. There is no Paystack or Flutterwave integration. Currency is GHS only, stored as whole pesewas.
